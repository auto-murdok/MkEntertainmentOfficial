# Mansion environment

The `LV_Haunted_Mansion` estate (UE5 original, reconstructed 1:1 in
Blender — see `blender-playground/tests/new_mansion/` and
`docs/mansion-rebuild.md` there) as stackable Unity prefabs, composed
from additively loaded chunk scenes.

Architecture (researched gold standard, 2026-10-24; plan page:
"Mansion as stackable prefabs — additive scene architecture"):

- **Source/** — the only hand-curated inputs. FBX per unique mesh,
  textures, and `level_actors.json`, the placement manifest (per actor:
  label, class, kind, mesh, loc_cm, rot_pyr, scale — UE conventions,
  centimetres). One-way door: this folder layout and the FBX file
  identities/GUIDs are frozen once prefabs reference them.
  - `Kit/` — the 50-piece building kit FBX (cm-authored; Unity's FBX
    file-scale conversion normalises them — see the import
    postprocessor). 45 of the 50 are placed by the manifest.
  - `KitTextures/` — the kit's 54 textures (UE naming: `_B` colour,
    `_N` normal, `_ORM` packed data).
  - `Props/` + `PropTextures/` — the 161 mansion prop FBX (m-authored,
    real `FbxLODGroup`s) and their 277 textures. 132 of the 161 are
    placed by the manifest. The two `MansionProps*_manifest.csv` files
    are the packs' provenance manifests (mesh → texture sets).
  - `matlib_building_kit.json` — the kit material library definition
    (input to material consolidation in the prefab factory).
- **Materials/** — consolidated URP materials, extracted once by the
  prefab factory. Never hand-author per-mesh materials.
- **Prefabs/** — generated wrapper prefabs, one per unique mesh
  (211 base wrappers + 30 mirrored `_M` variants for this level):
  root = logical snap point (per-class pivot
  convention), `PivotOffset` child carrying the model, LODGroup,
  collider proxy, footprint metadata. Generated by
  `MansionPrefabFactory` — regenerate, don't hand-edit.
- **Scenes/** — generated chunk scenes (Core + per-zone Shell/Interior
  + Grounds sectors), built by `MansionSceneBuilder` from the manifest
  and loaded additively at runtime through the `IMapLoader` seam.
  Load group = lightmap bake group = occlusion bake group.

Verification record, the gap-bug root cause, and pipeline gotchas:
`docs/mansion_pipeline_notes.md`.

Tooling lives in `Assets/_Game/Scripts/Editor/Mansion/`
(`MansionImportPostprocessor`, `MansionPrefabFactory`,
`MansionSceneBuilder`). Manifest coverage is pinned by EditMode tests
(`Assets/_Game/Tests/EditMode/Environments/`): 2,615 static-mesh
placements, 178 unique meshes = 45 kit + 132 props + 5 × `Plane`
(engine shape, recreated natively by the builder).
